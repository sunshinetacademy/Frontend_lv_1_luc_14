اختبار شامل — 10 أسئلة من كل المحاضرات

اختبر نفسك — لو جاوبت 8/10 فأكثر، أنت جاهز للمستوى الثاني!

سؤال 1

ما هو العنصر Semantic اللي بيحتوي على المحتوى الرئيسي للصفحة (مرة واحدة فقط)؟

  • أ <div>
  • ب <main>
  • ج <section>
  • د <article>
سؤال 2

ما هو الفرق بين Class و ID؟

  • أ مفيش فرق
  • ب Class فريد، ID يتكرر
  • ج Class يتكرر، ID فريد
  • د Class للنصوص، ID للألوان
سؤال 3

ما هو Box Model بالترتيب من الداخل للخارج؟

  • أ Margin, Border, Padding, Content
  • ب Content, Padding, Border, Margin
  • ج Content, Border, Padding, Margin
  • د Padding, Content, Border, Margin
سؤال 4

ما هو value اللي بيخلي العناصر تتوزع على السطر مع مسافات متساوية؟

  • أ justify-content: center
  • ب justify-content: space-between
  • ج align-items: center
  • د flex-direction: row
سؤال 5

ما هي وحدة fr في Grid؟

  • أ fixed ratio
  • ب fraction — جزء من المساحة الفاضية
  • ج frame rate
  • د full row
سؤال 6

ما هو clamp()؟

  • أ دالة لتحديد قيمة ثابتة
  • ب دالة لقيمة مرنة بين حد أدنى وأقصى
  • ج دالة لإخفاء العناصر
  • د دالة لتكبير العناصر
سؤال 7

ما هو الـ syntax الصحيح لتعريف CSS Variable؟

  • أ $color: red;
  • ب @color: red;
  • ج --color: red;
  • د var-color: red;
سؤال 8

ما هو property اللي بيخلي الحركة سلسة؟

  • أ animation
  • ب transition
  • ج transform
  • د motion
سؤال 9

في Mobile-first approach، أي media query نستخدم؟

  • أ max-width
  • ب min-width
  • ج exact-width
  • د device-width
سؤال 10

ما هو أفضل طريقة لتوسيط عنصر أفقياً ورأسياً؟

  • أ margin: auto
  • ب display: flex + justify-content: center + align-items: center
  • ج text-align: center + vertical-align: middle
  • د position: absolute + top: 50% + left: 50%

📌 ملخص الرحلة — ما تعلمته في المستوى الأول

  • HTML = هيكل الصفحة (العظام)
  • Semantic HTML = هيكل ذو معنى (لـ SEO و Accessibility)
  • Forms + Tables = تفاعل مع المستخدم
  • Media + Meta = صفحة متكاملة واحترافية
  • CSS = تصميم الصفحة (الملابس والديكور)
  • Box Model = أساس كل تصميم في CSS
  • Display + Position = التحكم في العرض والموقع
  • Flexbox = Layout أحادي البعد (قوي وسهل)
  • Grid = Layout ثنائي البعد (للتخطيطات المعقدة)
  • Responsive = موقع واحد يعمل على كل الأجهزة
  • Advanced CSS = اللمسات الاحترافية (Variables, Shadows, Transitions)
  • Projects = التطبيق العملي هو أفضل طريقة للتعلم
  • Best Practices = الكود النظيف = المطور المحترف
